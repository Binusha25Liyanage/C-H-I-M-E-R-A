The login Chimera uses for SFA Automation. Test Connection logs in with a real browser and reports success only if SFA accepts the login; the screenshot shows what SFA displayed.

Daily report rules

Applied to the next generated report. Targets: a territory is highlighted in the Hourly report when it meets BOTH its bill and value target.

Manager groups

Which territories belong to which manager, and whether each is Van or Pre selling. Also updated by the Territories import on the Import Data screen (columns Group, Territory, Sale Model).

Data saver

Don't download images and fonts from SFA

Applies to automated SFA runs (scheduled, Run now and profile tests). Logos, icons, pictures and web fonts are skipped; filters, Search and Export work the same. SFA may look plain if you watch it. WhatsApp sending is not affected.

Data used by SFA automation

Measured by Chimera from the browser's own network counters: everything a run sends and receives, including the downloaded reports. Runs from before this update aren't counted.

ABOUT THE APPLICATION

C H I M E R A

Chimera brings sales-operations work into one place: it downloads the day's reports from SFA automatically, checks every file, builds the SKU, Pivot and Hourly reports, and delivers them — replacing slow, manual, error-prone steps with a process that is fast, precise and repeatable.
